# Презентация проекта

Рабочая версия от 21.09.2026, 8 слайдов. Это промежуточная презентация: согласованная архитектура отделена от реализованных и проверенных частей.

- [PowerPoint](virtual_board.pptx) — редактируемая копия для просмотра и выступления.
- [PDF](virtual_board.pdf) — просмотр с фиксированным оформлением.
- [LibreOffice Impress](virtual_board.odp) — основной редактируемый файл; схемы и тексты являются объектами слайдов.
- [Заметки к выступлению](SPEAKER_NOTES.md) — пояснения к каждому слайду и вопросы для подготовки.

После завершённого функционального блока обновляем соответствующий слайд по [отчёту](../REPORT.md), затем повторно экспортируем ODP в PPTX и PDF. Не редактируем независимо обе копии презентации. Испытания, не проведённые на модуле, не переносим в раздел подтверждённых результатов.

Перед защитой уточняем регламент выступления, заменяем промежуточный статус итоговым, добавляем фактические результаты проверки всех требований Medium и окончательный сценарий демонстрации. Текущий слайд «Следующие этапы» затем заменяем итогами и ограничениями.

Основа содержания: [отчёт](../REPORT.md), [протокол](../PROTOCOL.md), рабочие документы `Project/documents/`. Источником результатов 17–21 сентября является вывод терминала, предоставленный пользователем и сохранённый в отчёте.

Обновление 21.09: слайд 6 объясняет проверенный путь команды через workqueue/completion; слайд 7 содержит результаты temp/limits, границ, отказов и выгрузки; слайд 8 начинается с первого CAN-кадра. Экспорты PDF/PPTX обновлены из ODP, оформление изменённых слайдов проверено.

В том же обновлении добавлены результаты подготовки CAN-сокета: успешная привязка и выгрузка, отказы vb_missing/lo. Слайды 3, 7 и 8 обновлены; PDF/PPTX повторно экспортированы, оформление проверено. Отправка кадров пока не заявляется.


## Обновление: первый CAN-кадр, 21.09

Проверен путь write → workqueue → kernel_sendmsg → candump. Получены 0x124 с payload 52036400BC020201 (перегрев) и FA006400BC020001 (норма). temp 900 не создал повторного уведомления. stop запретил кадры, temp 850 продолжил локальный контроль; отсутствие новых кадров подтверждено пользователем. Выгрузка успешна (18627.596263), регистрации удалены. На слайдах 1, 3, 5–8 отражён результат. Таймер/0x123, FIFO/read и остальные интерфейсы пока не проверены и не заявляются готовыми. Прежние 17 предупреждений check относятся к версии до CAN.


## Периодический статус — 21.09

Источник: REPORT.md, 5.16. hrtimer ставит tx_work в ordered workqueue, worker отправляет снимок только в running. При period_ms=1000 в candump измерен интервал около 1 с; первые два кадра разделены 1,000008 с. Пользователь подтвердил прекращение кадров по stop и возобновление после start. Пауза между кадрами — 22,063533 с. Завершающий stop вернул 0, выгрузка успешна (24630.858614). Модуль выгружен. Повторные команды без смены состояния, совместная работа 0x123/0x124 и период 100 мс ещё требуют проверок. Слайды 7–8 обновлены. Предыдущие записи выше описывают историю этапов.
