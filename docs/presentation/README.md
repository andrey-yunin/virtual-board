# Презентация проекта

Рабочая версия от 18.09.2026, 8 слайдов. Это промежуточная презентация: согласованная архитектура отделена от реализованных и проверенных частей.

- [PowerPoint](virtual_board.pptx) — редактируемая копия для просмотра и выступления.
- [PDF](virtual_board.pdf) — просмотр с фиксированным оформлением.
- [LibreOffice Impress](virtual_board.odp) — основной редактируемый файл; схемы и тексты являются объектами слайдов.
- [Заметки к выступлению](SPEAKER_NOTES.md) — пояснения к каждому слайду и вопросы для подготовки.

После завершённого функционального блока обновляем соответствующий слайд по [отчёту](../REPORT.md), затем повторно экспортируем ODP в PPTX и PDF. Не редактируем независимо обе копии презентации. Испытания, не проведённые на модуле, не переносим в раздел подтверждённых результатов.

Перед защитой уточняем регламент выступления, заменяем промежуточный статус итоговым, добавляем фактические результаты проверки всех требований Medium и окончательный сценарий демонстрации. Текущий слайд «Следующие этапы» затем заменяем итогами и ограничениями.

Основа содержания: [отчёт](../REPORT.md), [протокол](../PROTOCOL.md), рабочие документы `Project/documents/`. Источником результатов 17–18 сентября является вывод терминала, предоставленный пользователем и сохранённый в отчёте.
